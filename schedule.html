📖 일정관리 사용법

기본 사용

  • [＋ 행 추가]로 새 일정을 만들고, 셀을 클릭하면 바로 수정됩니다. 한 줄 칸은 Enter로 확정, 제목·내용 같은 여러 줄 칸은 Shift 없이 Enter로 줄바꿈됩니다.
  • 행은 기본 2줄 높이로 보이고, 클릭하면 내용 전체 높이로 펼쳐집니다. 다른 곳을 클릭하면 다시 접힙니다.
  • 맨 왼쪽 체크박스로 여러 행을 골라 상단 바에서 상태 일괄 변경·중요 표시·복제·삭제를 할 수 있습니다. 행 오른쪽 ⧉로 한 건만 복제할 수도 있습니다.
  • 상세구분·구분·책임·개발자 칸은 클릭하면 기존에 입력된 값 목록에서 고를 수 있어 표기 불일치를 줄입니다(직접 입력도 가능).
  • 상단 [▦ 열]에서 표시할 컬럼을 켜고 끌 수 있으며(선택은 저장됨), [화면만 내보내기]는 현재 필터·검색으로 보이는 항목만 엑셀로 내보냅니다.
  • ★를 누르면 중요일정으로 등록되어 중요일정 탭과 알림에 나타납니다.
  • 열 제목의 ▾를 누르면 엑셀처럼 값 선택 필터를, 날짜·숫자 열은 범위 필터를 걸 수 있습니다. 상단 검색은 모든 칸을 대상으로 합니다.
  • 하단 [⇤ 처음] [끝 ⇥]은 제목이 입력된 첫/마지막 일정으로 이동합니다.
  • 상단 툴바의 🌙로 다크 모드를, ≡로 행 간격(넓게/좁게)을 전환할 수 있습니다. 선택은 자동 저장되어 다음에 열 때도 유지됩니다.
  • 헤더 아래 상태 요약 줄에서 상태별 건수와 지연·임박을 한눈에 보고, 상태 칩을 누르면 해당 상태만 걸러 볼 수 있습니다. 걸린 필터는 필터 칩으로 표시되며 ✕로 하나씩 해제합니다.
  • 상단 [📋 표] [📅 캘린더] [📊 타임라인] [📈 분석]으로 보기 방식을 바꿀 수 있습니다. 캘린더는 개발완료예정 기준 월간 배치, 타임라인은 접수일자~개발완료예정 기간 막대, 분석은 월별/연별 접수·완료 추이와 제목 앞 [태그] 기반 프로젝트·유형·중요일정 통계를 보여줍니다. 항목(달력 일정·막대·랭킹)을 클릭하면 표로 이동합니다. 필터·검색·전체/중요 탭은 모든 보기에 함께 적용됩니다.

저장 · 백업

  • [저장 위치 설정]에서 폴더를 한 번 지정하면(권장: E:\_work\_github\link-vault ) 이후 [데이터 저장]은 대화창 없이 그 폴더에 바로 저장됩니다. 5분마다 변경사항이 있으면 자동 저장됩니다.
  • 저장할 때마다 직전 파일이 _백업1 ~ _백업5로 순환 보관됩니다(백업1이 가장 최신 이전본). 실수로 잘못 저장해도 백업 파일을 [데이터 불러오기]로 열어 복구할 수 있습니다.
  • 여기에 더해 날짜별 백업도 하루에 하나 보관됩니다. 그날 처음 저장(또는 불러오기)할 때 일정관리_data_YYYYMMDD.json이 없으면 만들고, 이미 있으면 그대로 둡니다. 순환 백업과 달리 날짜별로 계속 남아 특정 날짜 상태로 되돌리기 좋습니다.
  • 엑셀 내보내기/가져오기도 지원합니다. 내보낸 파일은 PROJECT 시트(중요·알림 열 포함)와 중요메모 시트(직접입력 항목)로 구성되며, 다시 가져오면 그대로 복원됩니다.

중요일정 알림

  • [🔔 중요알림] 버튼으로 열거나, 5분간 화면 동작이 없으면 자동으로 뜹니다. 남은 시간은 하단에 카운트다운으로 표시됩니다.
  • 목록은 개발완료예정 빠른 순(없으면 접수일자 순)으로 정렬되고, 완료예정일이 지난 항목은 주황(완료됨) 또는 빨강(미완료)으로 강조됩니다.
  • 각 항목의 [알림] 체크를 끄면 자동 알림에서 빠지고, 전체/표시/미표시 탭으로 관리합니다. No를 클릭하면 알림이 닫히며 해당 업무로 바로 이동합니다.
  • [＋ 직접입력 추가]로 일정 목록과 무관한 중요일정을 알림에만 등록할 수도 있습니다.
  • 알림 창 아래쪽에는 중요 표시가 없어도 개발완료예정이 지났는데 미완료인 지연된 일정이 함께 표시되며, No를 누르면 해당 업무로 이동합니다.

두레이 업무 가져오기 (두레이복사 북마클릿)

두레이 업무 화면의 정보를 클릭 한 번으로 복사해, CODE 칸에 붙여넣으면 CODEHIDDEN · CODE(링크) · 제목 · 내용 · 요청(등록자) · 접수일자(등록일)가 자동 입력되는 기능입니다.

최초 1회 — 북마크 만들기

  1. 브라우저에서 Ctrl+Shift+B로 북마크바를 켭니다.
  2. 북마크바 빈 곳 우클릭 → 페이지 추가(북마크 추가).
  3. 이름은 두레이복사, URL에는 아래 코드를 통째로 붙여넣고 저장합니다.

평소 사용법

  1. 두레이에서 등록할 업무 화면을 엽니다.
  2. 북마크바의 [두레이복사]를 클릭 → "복사 완료" 알림이 뜹니다.
  3. 이 화면에서 [＋ 행 추가] 후 CODE 칸에 붙여넣기(Ctrl+V) → 각 칸에 자동으로 나눠 들어갑니다.
  • 접수일자의 연도는 자동 추정됩니다(오늘보다 미래인 월·일이면 작년으로 판단).
  • 등록자를 화면에서 못 찾으면 요청 칸만 비어서 들어오니 직접 입력하면 됩니다.
  • 두레이 API 토큰이 있다면 [저장 위치 설정]에 넣어두고 링크만 붙여넣는 방식도 가능합니다(회사망·브라우저 정책에 따라 차단될 수 있음).
