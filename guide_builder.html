사용 가이드

가이드 빌더, 이렇게 쓰세요

왼쪽에서 내용과 구성을 편집하면 오른쪽 미리보기에 바로 반영돼요. 다 되면 HTML로 내보내기 하면 끝입니다.

1

구조 편집 왼쪽 · C. 콘텐츠

분야 › 중분류 › 항목의 3단계까지 구성할 수 있어요. 분야 안에 항목을 바로 두거나(2레벨), + 중분류(하위 그룹) 추가로 묶을 수 있습니다(3레벨). 상세기준·증빙은 한 줄에 하나씩 적으면 목록·체크박스가 되고, 줄 앞에 # 를 붙이면 그룹 소제목이 됩니다. 왼쪽 ⠿ 손잡이로 분야·중분류·항목·블록을 드래그 이동(↑ ↓도 지원), ⧉ 복제 · ✕ 삭제 · 실행 취소(Ctrl+Z)/다시(Ctrl+Y)까지 됩니다.

2

트래커 · 블록 항목 편집 안

각 항목에 상태(예정/진행/완료) · 우선순위 · 담당자 · 기한 · 태그를 넣으면 업무 트래커가 됩니다(완성본에서 배지 표시 + 태그 필터). 또한 항목 안에 추가 블록 9종 — 소제목 · 문단 · 안내 박스(정보/팁/주의) · 목록 · 표 · 링크 · 이미지 · 코드 · 구분선 — 을 자유롭게 쌓고 ⠿ 손잡이로 드래그 정렬할 수 있어요. 진행률은 항목→중분류→분야→전체 링으로 합산됩니다. 항목의 일정(간트) 칸에 시작·종료일이나 구간(이름 | 시작 | 종료 | 종류)을 넣고 레이아웃을 간트로 바꾸면 일정 막대로 그려지고, 마일스톤 체크는 세로 가이드선으로 표시됩니다.

3

구성 선택 왼쪽 · B. 구성

레이아웃 6종(아코디언·표·카드·칸반·간결·간트)과 테마 8종(페이퍼·슬레이트·샌드·포레스트·로즈·다크·미드나잇·모노), 밀도, 표시 기능을 고릅니다. 간트는 항목의 시작·종료일이나 구간(단계)을 막대로, 기한을 마일스톤으로 그려 일정 타임라인을 만들어 줍니다. 헤더 문구 패널에서는 제목·푸터와 섹션 명칭(상세기준·증빙 등)도 바꿀 수 있어요.

4

완성본 기능 미리보기 · 내보낸 파일

  • 검색창 · 태그 필터 — 항목을 빠르게 찾기
  • 테마 전환 버튼 — 보는 사람이 테마 선택(기억됨)
  • 진행률 링 · 분야별 막대 — 준비 상태를 한눈에
  • 인쇄 / PDF — 제출용으로 깔끔하게 출력
5

저장 · 내보내기 상단 오른쪽

  • HTML 내보내기 — 자동저장·체크리스트가 담긴 배포용 단독 파일
  • 프로젝트 저장 / 열기 — .guide.json으로 백업·복원해 이어서 편집
  • CSV 가져오기 / 내보내기 — 엑셀에 정리한 분야·중분류·항목·담당·상태·태그·증빙을 한 번에 대량 등록하거나 CSV로 저장(교체/추가 선택) · MD 내보내기는 위키·노션에 붙일 마크다운 문서
  • 샘플 불러오기 — 40종을 7개 카테고리(기본·일정/간트 신규·종합·IT 개발/DevOps·IT 인프라/보안·업무·일반)로 정리해 제공. 일정을 짜려면 일정 · 간트 ✦ 신규 카테고리를, 처음이라면 전 기능 총망라 (레퍼런스) 를 열어 보세요. 비우기로 새로 시작할 수도 있어요.
