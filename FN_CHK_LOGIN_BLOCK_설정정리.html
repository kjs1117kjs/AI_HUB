FN_CHK_LOGIN_BLOCK 스위치 설정 정리

국외 IP 로그인 차단 — 판정 함수 운영 모드 가이드 (작성일 2026.08.28)

1. 스위치 2개

스위치값의미
C_BLOCK_MODE 'N' 관찰 모드 — 차단 대상이어도 통과('M'), 이력만 기록
'Y' 차단 모드 — 차단 대상은 'N' 리턴 → 트리거가 RAISE (로그인 실패)
C_CHK_TARGET 'S' SMS 등록자만 검사 — 미등록자는 판정·이력 없이 즉시 'Y'
'A' 전체 사용자 검사 — 미등록자도 판정·이력·차단 대상

2. 조합별 동작

국외 IP + 허용테이블(TB_CM_IP_ALLOW) 미등재인 경우 기준.

조합SMS 등록자SMS 미등록자용도
N + S 통과 + 이력 [SMS=Y] 통과, 이력 없음 등록자만 관찰 (원본 초기 상태)
N + A현재 통과 + 이력 [SMS=Y] 통과 + 이력 [SMS=N] 전체 관찰 — 아무도 차단되지 않음
Y + S 차단 + 이력 통과, 이력 없음 등록자만 차단
Y + A 차단 + 이력 차단 + 이력 전체 차단 (최종 목표)

3. 조합과 무관하게 항상 동일한 것

  • 한국 IP → 무조건 'Y' 허용, 이력 없음
  • TB_CM_IP_ALLOW 등재자 (기간·USE_YN 유효) → 국외여도 'Y' 허용, 이력 없음
  • 판정 중 오류 발생 → 'Y' 허용 (전체 로그인 장애 방지 — fail-open)
  • 메뉴 접근 (FN_GET_MENU_CHK_YN2, p_log_yn=>'N') → 판정은 동일하게 수행, 이력만 생략
  • 이력 라벨: 관찰 모드 MONITOR - ..., 차단 모드 BLOCKED - ...
주의 — fail-open 구조: 판정 중 내부 오류(테이블 없음·권한 문제 등)가 발생하면 에러 없이 조용히 'Y'로 허용됩니다. 이력이 예상보다 적으면 "국외 접속이 없는 것"인지 "함수가 예외로 빠지는 것"인지 단독 테스트(SELECT FN_CHK_LOGIN_BLOCK('I', NULL, '아이디', '8.8.8.8') FROM DUAL → 'M' + 이력 1건)로 검증 필요.

4. 리턴값 의미

리턴의미트리거(R90) 처리
'Y'허용 (한국 IP / 허용테이블 / 검사 제외 대상)통과
'M'차단 대상이지만 관찰 모드라 통과 (이력 기록)통과
'N'차단 (이력 기록)RAISE → 로그인 실패

5. 운영 시나리오 (권장 순서)

  1. N + A (현재) — 전체 국외 접속 현황 수집
  2. 이력에서 [SMS=Y] 건 검토 → 정당한 해외 사용자는 허용테이블(TB_CM_IP_ALLOW) 등재
  3. Y + S — 등록자부터 차단 개시
    ※ 이 조합에서는 미등록자 이력도 안 남는 점 주의 — 미등록자 이력을 유지하려면 이 단계를 건너뛰고 4로
  4. Y + A — 전체 차단
스위치 변경은 함수 상수 두 줄 수정 후 재컴파일만 하면 됩니다. 트리거(TR_TB_WB_LOGIN_HIST_R90)·메뉴 함수(FN_GET_MENU_CHK_YN2)는 수정 불필요.

6. 이력 확인 쿼리

목적쿼리
등록/미등록 구분 집계 SELECT CASE WHEN BLOCK_REASON LIKE '%[SMS=Y]%' THEN 'SMS등록' ELSE '미등록' END AS SMS_DIV, COUNT(*) CNT, COUNT(DISTINCT USER_ID) USER_CNT FROM TB_WB_LOGIN_HIST_BLOCK GROUP BY CASE WHEN BLOCK_REASON LIKE '%[SMS=Y]%' THEN 'SMS등록' ELSE '미등록' END
차단 전환 시 영향받을 사용자 SELECT DISTINCT USER_ID, REAL_IP, COUNTRY_CODE FROM TB_WB_LOGIN_HIST_BLOCK WHERE BLOCK_REASON LIKE '%[SMS=Y]%'
