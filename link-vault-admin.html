링크 관리

링크를 등록·수정한 뒤 links.json 다운로드로 파일을 받아 GitHub 저장소에 커밋하면 조회 페이지에 반영됩니다.

URL은 비밀번호로 암호화되어 저장됩니다. links.json에는 평문 URL과 비밀번호가 들어가지 않으며, 한 번 등록한 항목의 원본 URL·비밀번호는 이 화면에서도 다시 볼 수 없습니다 (수정 시 URL·비밀번호를 새로 입력).
수정 모드: URL과 비밀번호를 다시 입력해야 합니다 (암호화 저장이라 기존 값을 불러올 수 없음).
GitHub Pages 주소를 입력해 두면 아래 목록에서 번호가 포함된 공유 링크를 바로 복사할 수 있습니다. (예: 주소 끝에 ?n=3이 붙은 링크)
links.json을 불러오거나 새 링크를 추가하세요.
선택된 파일 없음
보통 이 페이지를 등록할 링크 번호의 비밀번호와 같게 설정합니다 — 받는 사람이 비밀번호 하나만 기억하면 됩니다.
암호화된 HTML: 원본 페이지가 그대로 동작 (클릭·입력 가능). 단, 비밀번호를 아는 사람은 개발자도구로 소스를 볼 수 있음.
암호화된 이미지 HTML: 페이지를 통째로 이미지로 변환해서 담음. 소스가 아예 없어 누구도 볼 수 없지만, 링크 클릭·입력 등 모든 동작이 사라짐 (읽기 전용 문서에 적합).
다운로드된 파일을 저장소에 업로드하고, 그 주소를 위에서 링크로 등록해 공유하세요. 원본 파일은 업로드하지 마세요.
다운로드한 links.json을 저장소 루트(index.html 옆)에 넣고 커밋·푸시하세요. 기존 파일을 불러오면 이어서 추가·수정할 수 있습니다.

사용 가이드

이 시스템의 구성

세 파일로 이루어져 있습니다.

  • index.html — 조회 페이지. GitHub Pages에 올려 사람들에게 공유하는 화면.
  • links.json — 링크 데이터. URL이 비밀번호로 암호화되어 저장됨. index.html 옆에 함께 업로드.
  • admin.html — 지금 이 화면. 내 컴퓨터에만 보관하고 GitHub에는 올리지 않아도 됨.

처음 배포하기

  1. GitHub에서 Public 저장소 생성 (예: link-vault)
  2. 이 화면에서 링크를 등록하고 [links.json 다운로드]
  3. 저장소에 index.html과 links.json 업로드 (Add file → Upload files)
  4. Settings → Pages → Branch: main / (root) → Save
  5. 1~2분 후 https://아이디.github.io/저장소이름/ 주소 생성
  6. 이 주소를 상단 "공유 링크 설정"에 입력해 두기

링크 등록·수정·삭제

  1. 번호·비밀번호·이름·URL을 입력하고 [저장]
  2. 수정 시에는 URL과 비밀번호를 다시 입력해야 함 (암호화 저장이라 기존 값을 불러올 수 없음)
  3. 변경 후에는 반드시 [links.json 다운로드] → 저장소의 기존 파일 위에 재업로드해야 반영됨
  4. 이어서 작업할 때는 [기존 links.json 불러오기]로 현재 파일을 먼저 로드
원본 URL·비밀번호 목록은 이 화면에서도 다시 볼 수 없으니, 엑셀·메모 등에 따로 보관해 두세요.

공유하기

  1. 목록에서 [공유 링크 복사] → ...?n=번호 형태의 링크가 복사됨
  2. 이 링크로 들어온 사람은 번호 입력 없이 비밀번호 입력창이 바로 열림
  3. 비밀번호는 링크와 다른 채널(예: 링크는 메일, 비밀번호는 메신저)로 전달하면 더 안전

페이지 암호화 — 내가 만든 HTML을 잠가서 올리기

공유하려는 HTML 파일 자체를 같은 저장소에 올릴 때 사용합니다. 그냥 올리면 주소를 아는 누구나 볼 수 있으므로, 반드시 암호화해서 올려야 합니다. 두 가지 방식이 있습니다.

  • 암호화된 HTML — 원본 페이지가 그대로 동작 (클릭·입력 가능). 단, 비밀번호를 아는 사람은 개발자도구로 소스를 볼 수 있음.
  • 암호화된 이미지 HTML — 페이지를 통째로 이미지로 변환. 소스가 존재하지 않아 누구도 볼 수 없지만, 클릭·입력 등 모든 동작이 사라짐. 읽기 전용 문서에 적합.
  1. [HTML 파일 선택]으로 원본 파일 선택
  2. 페이지 비밀번호 입력 — 등록할 링크 번호의 비밀번호와 같게 하는 것을 추천 (받는 사람이 하나만 기억)
  3. 두 버튼 중 하나로 다운로드 → 파일을 직접 열어 화면 확인 → 저장소에 업로드
  4. 업로드된 주소(예: .../test.html)를 URL로 하여 링크 등록 → 공유
원본(암호화 전) 파일은 절대 저장소에 올리지 마세요. 이미지 방식도 화면을 보는 사람의 스크린샷·촬영까지는 막을 수 없습니다.

자주 묻는 것

  • 반영이 안 돼요 — 파일을 올린 뒤 Pages 반영까지 1~2분 걸립니다. 브라우저 캐시일 수 있으니 강력 새로고침(Ctrl+Shift+R)도 해보세요.
  • 비밀번호를 잊었어요 — 복구 불가입니다. 해당 번호를 새 비밀번호로 다시 등록(수정)하고, 암호화 페이지도 다시 만들어 올리세요.
  • admin.html을 잃어버렸어요 — links.json만 있으면 새 admin.html에서 [기존 links.json 불러오기]로 이어서 관리할 수 있습니다. admin.html도 안전한 곳에 백업해 두세요.
  • 보안 한계 — 정적 사이트라 비밀번호 반복 시도 자체는 막을 수 없습니다. 짧은 숫자보다 어느 정도 긴 비밀번호를 권장합니다.
