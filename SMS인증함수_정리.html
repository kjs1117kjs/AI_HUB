SMS 인증 함수 — FN_GET_TB_CM_SMS_VFC_CODE

SMS 사용 등록 확인, 로그인·추가 인증번호 발급과 검증, 국외 IP 차단을 하나의 함수로 처리합니다. 결과는 "코드(2자리)|메시지" 문자열로 돌려줍니다.

스키마 SBPORA AUTONOMOUS_TRANSACTION CHK · CDI · C10 · C11 · C20 · C21 작성일 2026-10-02

-- 호출 예시
SELECT FN_GET_TB_CM_SMS_VFC_CODE('kjsun1117', 'CHK', '',       '')               FROM DUAL;
SELECT FN_GET_TB_CM_SMS_VFC_CODE('kjsun1117', 'CDI', 'DI값',   '')               FROM DUAL;
SELECT FN_GET_TB_CM_SMS_VFC_CODE('kjsun1117', 'C10', '',       '211.104.152.65') FROM DUAL;
SELECT FN_GET_TB_CM_SMS_VFC_CODE('kjsun1117', 'C11', '123456', '211.104.152.65') FROM DUAL;
SELECT FN_GET_TB_CM_SMS_VFC_CODE('kjsun1117', 'C20', '',       '211.104.152.65') FROM DUAL;
SELECT FN_GET_TB_CM_SMS_VFC_CODE('kjsun1117', 'C21', '123456', '211.104.152.65') FROM DUAL;

-- 사용자별 최근 인증번호 이력 (인증번호 값은 암호화되어 있어 조회하지 않음)
SELECT  USER_ID, SEQ, VFC_DIV_CD, VFC_NO_CRT_DT, VFC_SUCC_DT, VFC_FAIL_CNT, MOD_DT
FROM    TB_CM_SMS_VFC_CODE
WHERE   USER_ID = :USER_ID
ORDER BY VFC_NO_CRT_DT DESC, SEQ DESC;

-- 현재 실패 잠금 중인 사용자 (1시간 이내 실패 5회)
SELECT  USER_ID, VFC_DIV_CD, MAX(MOD_DT) AS LAST_FAIL_DT
FROM    TB_CM_SMS_VFC_CODE
WHERE   VFC_FAIL_CNT >= 5
AND     MOD_DT >= TO_CHAR(SYSDATE - 1/24, 'YYYYMMDDHH24MISS')
GROUP BY USER_ID, VFC_DIV_CD
ORDER BY LAST_FAIL_DT DESC;

-- 오늘 발급 건수 상위 (C10 일 15회 한도 근접 확인)
SELECT  USER_ID, VFC_DIV_CD, COUNT(*) AS CNT
FROM    TB_CM_SMS_VFC_CODE
WHERE   VFC_NO_CRT_DT >= TO_CHAR(TRUNC(SYSDATE), 'YYYYMMDDHH24MISS')
GROUP BY USER_ID, VFC_DIV_CD
ORDER BY CNT DESC;

-- 테스트 계정 목록 (실사용 계정이 섞여 있지 않은지 점검)
SELECT  NMCODE_CD, NMCODE_NM
FROM    TB_CM_NMCODE
WHERE   NMCODE_GRP_CD = '249';

14확인 · 개선 사항

#항목내용구분
1테스트 계정 주석헤더·4단계 주석은 "A0001, A0002"로 되어 있으나 실제 로직은 TB_CM_NMCODE 249 조회. 주석을 실제 기준으로 맞출 필요주석
2트리거 이름이 함수 주석은 TR_TB_WB_LOGIN_HIST_R90, FN_GET_MENU_CHK_YN2 주석은 R98. 실제 트리거 이름 확인 필요확인
3난수 생성DBMS_RANDOM은 암호학적 난수가 아님. 보안 인증번호는 DBMS_CRYPTO.RANDOMINTEGER 사용 권장개선
4IP 미전달 시 판정 생략OP_FG3가 비면 국외 IP 판정을 건너뜀. 모든 호출부가 IP를 넘기는지 확인 (배치·내부 호출 포함)확인
5테스트 계정 고정 번호249 등록 계정은 123456으로 항상 통과. 운영 계정 등록 여부 정기 점검보안
6SMS 발송 실패 처리발송 프로시저 예외 시 발급 INSERT까지 ROLLBACK 후 -20001. 애플리케이션은 99로 변환해 안내참고
7잠금 수동 해제잠금은 시간 경과로만 풀림. 고객 문의 대응용 관리자 해제 기능 필요 여부 검토검토
