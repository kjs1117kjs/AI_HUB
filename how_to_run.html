추출 콘솔 — 실행 방법 & 기능 설명

이 파일은 설명서입니다(더블클릭으로 열려도 됨). 실제 도구는 start.bat 으로 실행하세요.

실행데모접속쿼리 분할고급옵션실행·진행결과·다운로드 저장·이력·예약문제해결폴더구성
기본 개념. 화면(브라우저)만으로는 조회가 안 됩니다. 뒤에서 파이썬 서버가 함께 켜져 있어야 해요. 구조: 브라우저 ↔ 파이썬 서버 ↔ Oracle. 그래서 HTML을 여는 게 아니라 start.bat 으로 서버를 켜고 브라우저로 접속합니다.
※ 앱 화면 오른쪽 위 도움말 버튼으로도 같은 설명을 볼 수 있어요.

1 실행 방법

준비 — 파이썬 (최초 1회)

명령프롬프트에서 python --version 을 쳐 버전이 나오면 준비 완료. 안 나오면 python.org 에서 설치하되 첫 화면의 “Add Python to PATH” 체크박스를 꼭 켜세요.

실행 — start.bat

📄 start.bat → 더블클릭
  • 검은 창(=서버)이 뜨고, 최초 1회만 패키지를 자동 설치합니다(인터넷 필요, 1~2분).
  • 설치가 끝나면 브라우저가 자동으로 열립니다. 안 열리면 http://127.0.0.1:8000 직접 입력.
  • 두 번째 실행부터는 설치를 건너뛰어 몇 초면 켜집니다.

완전 종료

검은 창을 닫으면 서버가 완전히 꺼집니다(또는 검은 창에서 Ctrl + C). 브라우저만 닫으면 서버는 계속 켜져 있어요. 파일을 바꾼 뒤엔 서버를 껐다 켜고 브라우저에서 Ctrl + F5.

2 데모 모드

화면 오른쪽 위 데모 모드를 켜면 DB 접속 없이 가짜 데이터로 전체 흐름 (분할 → 추출 → 로그 → 차트 → 다운로드)을 확인할 수 있습니다. 처음 익힐 때 유용합니다.

3 접속 정보

사용자 · 비밀번호 · DSN 입력 후 연결 테스트로 확인합니다. DSN 예: 10.0.0.10:1521/ORCLPDB1

  • 저장 / 불러오기: 접속 정보를 OS 자격증명 저장소(윈도우 자격증명 관리자)에 안전하게 보관하고 다시 불러옵니다.
비밀번호는 프리셋·이력에 저장되지 않습니다. 자격증명 저장소에만 별도로 보관됩니다.

4 쿼리 (기본 / 직접 편집)

  • 기본 쿼리: 내장 매출 쿼리 사용. 분할 조건이 자동 적용됩니다.
  • 직접 편집: “기본 쿼리 불러오기”로 내장 쿼리를 고치거나, 완전히 새 SQL을 붙여넣어 추출.

치환자 (직접 편집 시)

치환자설명
{where}분할·조건이 들어갈 위치. 분할 적용 시 필수.
{brands}브랜드 코드 IN 목록 (예: '100','101')
{office_cd}본부코드 값(문자)로 치환
:office_cd바인드 변수로도 사용 가능
  • 분할 조건 적용 체크: 켜면 {where}에 분할이 주입돼 구간별 실행, 끄면 통째로 1회 실행.
  • 결과 컬럼이 표준(매출일자·매장명·상품명·판매수량·총매출액·실매출액)과 다르면 차트·피벗은 자동 생략되고 CSV·엑셀·미리보기는 정상 동작.
  • 편집한 쿼리는 프리셋에 함께 저장됩니다.

5 분할 조건 (여러 축 조합)

축을 여러 개 걸면 조합(곱)만큼 구간이 생기고, 구간마다 CSV가 나옵니다. 순차 실행 시 구간 사이 쉬는 시간만큼 대기해 DB 부하를 줄입니다.

축동작예시
날짜 범위기간을 N일씩12/01~12/06을 3일씩 → 2구간
코드 범위숫자 코드를 N개씩 증가(자리수로 0채움)1~100을 10개씩 → 10구간(0001~0010…)
코드 목록코드 목록을 N개씩 묶음DS00001…을 3개씩 → 3개당 1파일
  • 대상 컬럼을 직접 지정합니다(예: tsdps.STORE_CD).
  • 코드 목록엔 SQL의 IN ( 'DS00001','DS00002',... )를 통째로 붙여넣어도 코드만 인식하고 중복은 자동 제거합니다.
  • 조합 예) 날짜(3일) × 코드범위(10개씩) = 2 × 10 = 20개 CSV. 화면에 2 × 10 = 20구간처럼 실시간 표시됩니다.

접혀 있어도 값은 항상 적용됩니다. 안 건드리면 기본값으로 동작합니다.

옵션설명기본

파일당 최대 행수50000 → 결과를 5만 행마다 _part02 파일로 분할 저장. 스트리밍이라 대용량 안전0(제한없음)

7 실행 · 진행 상황

  • 쿼리 검증: 실행 전에 쿼리 문법·객체·권한을 미리 확인(행을 가져오지 않고 파싱만). 잘못된 쿼리로 전체 구간이 실패하는 것을 방지합니다.
  • 예상 건수·시간: 첫 구간만 살짝 실행해 전체 건수·소요시간을 추정합니다.
  • 쿼리 미리보기: 값이 채워진 최종 SQL, 전체 구간 목록, 예상 대기시간 확인.
  • 추출 시작 후: 파이프라인 레일 + 진행률 바 + 실시간 로그 + 구간별 상태표(건수·소요시간·상태).
  • 중단: 현재 구간까지 마치고 멈춥니다.

8 결과 · 다운로드 · 시각화

  • 저장 폴더 열기: CSV가 저장된 폴더를 탐색기로 바로 엽니다. 다운로드를 안 눌러도 파일은 이미 output/<작업ID>/ 에 저장돼 있습니다.
  • 파일 목록: 각 파일 옆에 건수·소요시간이 함께 표시됩니다(행수 분할 파일은 part2 표기).
  • 엑셀 병합: 구간 CSV를 요약 시트 + 전체데이터 시트로 합칩니다. 엑셀은 시트당 약 104만 행 제한이 있어 수백만 건은 CSV/ZIP을 권장합니다.
  • 전체 ZIP: 구간별 CSV를 묶어 한 번에 내려받기(대용량 안전).
  • 차트(일자별 실매출·매장 Top·상품 Top) + 피벗 대시보드(행 기준 매장/상품/일자 × 값 실매출/총매출/수량 + 검색) + 상위 50행 미리보기.
  • 미리보기는 상위 50행만 표시하지만 CSV·엑셀에는 전체가 저장됩니다.
서버(검은 창)를 껐다 켜면 이전 작업의 다운로드 버튼은 동작하지 않습니다. 그땐 output 폴더에서 파일을 직접 꺼내세요.

9 저장 · 이력 · 예약 · 이메일 · 알림

  • 저장된 작업(프리셋): 현재 설정·분할조건·쿼리를 이름 붙여 저장/불러오기(비밀번호 제외). presets.json
  • 추출 이력: 완료된 추출이 자동 기록. 불러오기로 같은 조건 재실행. history.json
  • 예약 명령 만들기: 저장된 작업을 Windows 작업 스케줄러(schtasks)에 등록하는 명령을 생성. 실제 DB 예약은 자동실행 계정 환경변수 ORA_PW 가 필요합니다.
  • 완료 후 이메일 발송: 결과(엑셀 또는 ZIP)를 SMTP로 자동 전송.
  • 완료 알림: 추출이 끝나면 브라우저 팝업·소리로 알림.
  • 두레이 알림: 기본 꺼짐. 체크박스를 켜고 Incoming Webhook URL을 넣어야 발송됩니다. 테스트 전송 으로 연결을 먼저 확인하세요. 완료 시 채널로 건수·파일수·시간 요약이 전송됩니다.
  • 다크 모드: 헤더의 달/해 아이콘으로 화면 테마 전환(OS가 다크모드면 자동).

10 잘 안 될 때

증상해결
검은 창에 Python not found파이썬 미설치/PATH 누락. 설치 시 “Add Python to PATH” 체크.
패키지 설치 실패인터넷 확인. 사내망이 막으면 관리자에게 pip 허용 요청.
화면은 뜨는데 버튼이 안 먹음검은 창(서버)이 꺼졌는지 확인. 서버가 켜져 있어야 동작.
바꾼 내용이 화면에 반영 안 됨서버 재시작 후 브라우저에서 Ctrl + F5(강력 새로고침).
실제 조회 접속 실패사내망(VPN) 연결과 사용자/비밀번호/DSN 확인 후 연결 테스트.
직접 편집인데 시작 시 오류분할을 켰다면 쿼리에 {where} 가 있어야 합니다.
수백만 건 엑셀 병합 실패/느림엑셀 대신 CSV/ZIP 사용. 필요 시 “파일당 최대 행수”로 분할.
두레이 알림이 안 옴체크박스를 켰는지, URL이 맞는지 확인 후 “테스트 전송”. 사내망 방화벽이 외부 웹훅을 막을 수 있음.
브라우저 완료 알림이 안 뜸브라우저가 알림 권한을 물으면 “허용”. 정책으로 막히면 소리 알림만 동작.
