서버 접속 런처 사용설명서

목록에서 서버를 골라 PuTTY로 접속하고, 계정 정보를 한곳에 모아 두는 도구입니다.

01

시작하기 전에

파일 두 개를 같은 폴더에 두세요. 런처가 문서를 찾을 때 자기 옆을 봅니다.

아무 폴더\
  ├─ ServerLauncher_20260831_02.hta
  └─ server-restart-guide.html
  • PC에 PuTTY가 설치되어 있어야 합니다. 없으면 접속 버튼이 동작하지 않습니다.
  • 인터넷에서 내려받은 파일은 윈도우가 막아 둡니다. 파일 우클릭 → 속성 맨 아래에 차단 해제 체크박스가 있으면 체크하고 확인을 누르세요.
  • 파일 이름은 마음대로 바꿔도 됩니다. 런처가 자기 경로를 실행할 때 알아냅니다.
02

실행과 잠금

  1. hta 파일을 더블클릭합니다. 어두운 잠금 화면이 먼저 뜹니다.
  2. 관리자 비밀번호를 입력합니다. 맞으면 서버 목록이 나타납니다.
  3. 자리를 비울 때는 오른쪽 위 잠그기 를 누르세요. 다시 잠금 화면으로 돌아갑니다.

비밀번호를 또 물어보는 이유

접속, 비밀번호 복사, 추가정보 복사, 비밀번호 보기, 수정, 삭제는 그때마다 다시 확인합니다. 매번 입력이 번거로우면 상단 재인증 을 5분 유지 나 30분 유지 로 바꾸세요. 그 시간 안에는 묻지 않습니다.

관리자 비밀번호는 관리자 암호 변경 버튼으로 바꿀 수 있습니다. 바꾸면 파일에 바로 저장되고, 다음 실행부터 새 비밀번호를 씁니다.

03

화면 보는 법

화면은 위에서부터 설정 막대, 버튼 줄, 서버 목록, 편집 칸 순서입니다.

위치하는 일
맨 위 검은 줄 putty.exe 경로, 재인증 시간, 비밀번호 자동 입력 체크. 여기서 바꾼 값은 즉시 저장됩니다.
버튼 줄 검색창과 주요 버튼이 모여 있습니다. 검색창에는 서버 이름, IP, 계정, 추가정보가 모두 걸립니다.
서버 목록 줄을 클릭하면 아래 편집 칸으로 내용이 올라옵니다. 계정 줄을 더블클릭하면 바로 접속합니다.
편집 칸 서버를 추가하거나 고칠 때 씁니다.

정보 라고 표시된 줄

접속 계정 칸에 계정명 대신 메모가 들어 있는 줄입니다. SSH 계정이 아니라서 체크박스와 접속 버튼이 없습니다. 비밀번호 복사는 되므로 root 비밀번호처럼 보관 목적으로 쓰시면 됩니다.

04

서버 접속

방법이 세 가지입니다. 어느 쪽이든 관리자 비밀번호를 한 번 확인합니다.

방법설명
줄 더블클릭가장 빠릅니다. 그 서버 하나만 엽니다.
오른쪽 접속더블클릭과 같습니다.
체크 후 선택한 서버 접속여러 대를 한 번에 엽니다. WEB 2대와 WAS 2대를 동시에 띄울 때 편합니다.
  • 상단 비밀번호 자동 입력 이 켜져 있으면 PuTTY가 알아서 로그인합니다. 끄면 창만 열리고 비밀번호는 직접 입력합니다.
  • 추가정보가 있는 서버는 접속 직후 아래 메시지 줄에 접속 후: su - sbpnxpos 처럼 다음에 할 일이 표시됩니다.
  • 처음 접속하는 서버는 PuTTY가 호스트 키 확인 창을 한 번 띄웁니다. 수락하면 다음부터는 뜨지 않습니다.
05

비밀번호·정보 복사

비밀번호는 평소에 •••••••• 로 가려져 있습니다. 꺼내 쓰는 방법은 두 가지입니다.

한 줄만 복사

그 줄의 복사 버튼을 누르면 클립보드에 담깁니다. 화면에는 보이지 않으니 옆에서 볼 걱정이 없습니다. 추가정보 칸의 복사 도 같은 방식이라, su - nx_tomcat 같은 명령을 그대로 터미널에 붙여넣을 수 있습니다.

전체 펼쳐 보기

비밀번호 보기 를 누르면 모든 비밀번호가 화면에 나타납니다. 한 번 더 누르면 다시 가려집니다. 자리를 뜰 때는 반드시 다시 가리거나 잠그기 를 누르세요.

06

목록 관리

바꾼 내용은 hta 파일 안에 그대로 저장됩니다. 별도 데이터 파일이 없습니다.

하고 싶은 일순서
새로 추가아래 칸을 채우고 추가. IP와 접속 계정은 반드시 필요합니다.
고치기목록에서 줄을 클릭해 선택한 뒤 칸을 고치고 수정 저장.
지우기줄을 클릭해 선택하고 삭제. 한 번 더 확인을 묻습니다.
한꺼번에 넣기여러 줄 붙여넣기 를 누르고 엑셀에서 복사한 내용을 붙여넣습니다.

엑셀에서 붙여넣는 형식

한 줄에 서버 하나씩, 탭이나 쉼표로 나눕니다. 순서는 이렇습니다.

이름   IP   포트   계정   추가정보   비밀번호

추가정보가 없으면 그 칸에 X 를 넣으세요. IP나 계정이 빈 줄은 건너뜁니다.

저장할 때마다 옆에 파일이름.hta.bak 이 자동으로 생깁니다. 잘못 지웠을 때 이걸로 되돌릴 수 있습니다. 저장이 실패하면 화면 변경도 원래대로 되돌아가므로, 목록과 파일이 어긋나지 않습니다.

07

재기동 방법 문서

재기동 방법 을 누르면 같은 폴더의 server-restart-guide.html 이 기본 브라우저로 열립니다. 솔루션별 기동·종료 순서를 정리해 둔 문서입니다.

파일이 없으면 아래 메시지 줄에 어떤 이름을 찾고 있었는지 알려 줍니다. 문서 이름을 바꾸실 거면 hta 파일을 메모장으로 열어 위쪽 "guide" 항목만 고치면 됩니다.

09

보관 시 주의

비밀번호는 파일 안에 그대로 들어 있습니다

관리자 잠금은 실행했을 때 화면을 가려 주는 장치입니다. hta 파일을 메모장으로 열면 잠금과 상관없이 모든 계정 정보가 보입니다. 어깨너머로 보는 것은 막지만, 파일을 손에 넣은 사람은 막지 못합니다.

자동 생성되는 .bak 파일에도 같은 내용이 들어 있습니다. 같이 관리하세요.

  • 보관 위치 — C:\Users\사용자이름\ 아래 개인 폴더에 두세요. 공용 폴더, 공유 드라이브, 클라우드 동기화 폴더는 피하는 것이 좋습니다.
  • 공유 금지 — 파일 하나에 전부 들어 있어서, 런처를 건네주면 계정 정보도 함께 갑니다.
  • 공용 PC에서는 상단 비밀번호 자동 입력 을 끄세요. 켜져 있으면 PuTTY 실행 순간 명령줄에 비밀번호가 잠깐 노출됩니다.
  • 노트북이라면 BitLocker를 켜 두면 분실 시 도움이 됩니다.

계정 정보를 제대로 보호하려면 방향이 다릅니다. SSH 키 인증으로 바꿔 Pageant를 쓰면 런처에 비밀번호를 적지 않아도 되고, su - 는 sudo 권한 설정으로 대체하는 것이 정석입니다.
