가이드 빌더, 이렇게 쓰세요

왼쪽에서 내용과 구성을 편집하면 오른쪽 미리보기에 바로 반영돼요. 다 되면 HTML로 내보내기 하면 끝입니다.

1

내용 편집 왼쪽 · C. 콘텐츠

분야·항목을 눌러 펼치고 상세기준·증빙·주의사항·메모를 입력하세요. 상세기준과 증빙은 한 줄에 하나씩 적으면 자동으로 목록·체크박스가 됩니다. 분야마다 색으로 구분되고, ↑ ↓ 순서변경 · ⧉ 복제 · ✕ 삭제 · + 분야/항목 추가 · 전체 펼치기/접기가 가능합니다.

2

업무 트래커 항목 편집 안

각 항목에 상태(예정/진행/완료) · 우선순위 · 담당자 · 기한 · 태그를 넣으면 체크리스트가 업무 트래커가 됩니다. 완성본에는 상태·우선순위 배지와 담당·기한·태그가 표시되고, 태그 필터로 원하는 항목만 골라 볼 수 있어요.

3

구성 선택 왼쪽 · B. 구성

레이아웃 5종(아코디언·표·카드·칸반·간결)과 테마 8종(페이퍼·슬레이트·샌드·포레스트·로즈·다크·미드나잇·모노), 밀도, 표시 기능을 고릅니다. 헤더 문구 패널에서는 제목·푸터와 섹션 명칭(상세기준·증빙 등)도 바꿀 수 있어요.

4

완성본 기능 미리보기 · 내보낸 파일

  • 검색창 · 태그 필터 — 항목을 빠르게 찾기
  • 테마 전환 버튼 — 보는 사람이 테마 선택(기억됨)
  • 진행률 링 · 분야별 막대 — 준비 상태를 한눈에
  • 인쇄 / PDF — 제출용으로 깔끔하게 출력
5

저장 · 내보내기 상단 오른쪽

  • HTML 내보내기 — 자동저장·체크리스트가 담긴 배포용 단독 파일
  • 프로젝트 저장 / 열기 — .guide.json으로 백업·복원해 이어서 편집
  • 샘플 불러오기 — 온보딩·이사·출시 등 여러 예시 중 선택 / 비우기로 새로 시작
💡 작업 내용을 남기려면 먼저 프로젝트 저장을 누르세요. (편집기 자체는 자동 저장되지 않아요)
