백업 · 건수 확인

되돌릴 자리를 먼저 만들어 둡니다. 백업 테이블을 만든 뒤 건수를 적어 두고, 작업이 끝나면 같은 쿼리를 다시 돌려 비교하세요.

1

본사 → 본사 복사

원본 본사의 상품 마스터를 대상 본사로 옮깁니다. 분류 → 상품 → 상세정보 → 판매가 → 사이드메뉴 순서대로 실행해야 참조가 깨지지 않습니다.

2

본사 → 매장 복사

대상 본사에 들어간 정보를 소속 매장으로 내려보냅니다. 1단계를 먼저 끝내야 복사할 원본이 존재합니다.

3

정리 작업

복사 이후에 따로 돌리는 것들입니다. 이 항목은 대량 처리 모드와 관계없이 항상 프로시저로 만들어집니다.

4

MERGE 문 자동 생성기

여기 없는 테이블이 필요할 때 씁니다. 테이블명과 UNIQUE 컬럼만 넣고 실행하면 전체 컬럼을 읽어 MERGE 문을 만들어 출력합니다.
